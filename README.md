# AURA Resource Platform

Project structure prepared for a Firebase-only resource platform.

Public: index.html, resources.html, category.html, version.html, search.html, about.html

Admin: admin/index.html, dashboard.html, resources.html, items.html, materials.html, files.html, analytics.html, settings.html

Assets: one global CSS file at assets/css/style.css.

Security: firestore.rules and storage.rules.

Note: This ZIP is a structural starter package. Real Firebase CRUD/auth/storage/analytics implementation is not included yet. Replace Firebase configuration placeholders before integration.
